# Security policy

Please report suspected vulnerabilities privately through this repository's
**Security and quality → Report a vulnerability** form. The repository owner
must enable GitHub Private Vulnerability Reporting before public issue intake.
Do not post exploit details in public issues or pull requests.

Include the affected source revision, steps to reproduce, impact, and a minimal
example using synthetic data. Never send a real vault, master password, recovery
code, plaintext export, or unreviewed log. Maintainers will acknowledge and
coordinate disclosure through the private advisory.

Only the current source tree is in scope for this first source release. Windows
executables and the NSIS installer have not been verified for distribution.
