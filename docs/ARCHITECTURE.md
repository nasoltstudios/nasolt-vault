# Architecture

Nasolt Vault is a local Windows desktop application. `main.py` owns the CustomTkinter event loop, vault session, tray lifecycle, and startup routing. The `ui/` modules render the login, vault, settings, import/export, quick access, and Lockout Lab views. `quick_access.py` brokers Vault Summon authentication; `windows_shortcuts.py`, `windows_startup.py`, `windows_tray.py`, and `windows_hello.py` call Windows facilities. Background workers return results to Tk rather than updating widgets directly.

`paths.py` selects the data folder. `NASOLT_DATA_DIR` overrides it for isolated tests. Existing portable `data/vault.enc` remains authoritative; installed mode otherwise uses `%APPDATA%\Nasolt Vault\data`. The root application modules and `main.py` remain in place to preserve imports, PyInstaller discovery, and historical data paths. Never test against a real user data folder.

`vault.py` coordinates one unlocked session and an OS file lock. `crypto.py` implements the existing NSLT v1 envelope: Argon2id derived key and AES-256-GCM authenticated encryption. Saves use a unique temporary file and preserve a prior encrypted backup. `export.py` handles password-protected `.nve` exports and warned plaintext CSV/JSON formats. `lockout_lab.py` stores an optional encrypted sidecar derived from an unlocked vault session; its simulations use dependency metadata, not passwords. `hello_enrollment.py` stores authenticated preference metadata, not the master password or vault key. Windows Hello is session reauthentication only.

`packaging/windows/` contains NSIS installer source; `scripts/` contains Windows build scripts. Root `build.py`, `BUILD_WINDOWS.bat`, and `BUILD_INSTALLER.bat` are compatibility entry points. Build outputs go under ignored `artifacts/windows/`. `packaging/linux/` and `packaging/macos/` contain documentation only. `tests/` uses disposable synthetic vaults; `.github/workflows/` contains the Windows source test job. See [Threat model](THREAT_MODEL.md), [Release checklist](RELEASE_CHECKLIST.md), and [Windows packaging](../packaging/windows/README.md).
