## Phase B.1 verification (2026-10-21)

The approved local and remote `main` baseline is still `69faa59c46ba75835050bc19cb7081ece4dd9913`. These source changes remain uncommitted and unpublished. Static review found that a second unlock attempt could close an already open session; `VaultSession` now rejects a queued duplicate without disturbing the first session. Lock requests use a generation token before waiting on the session mutex, so earlier queued or running unlocks cannot reopen the vault after the lock completes. Canceling a locked Vault Summon authentication closes the session before the canceled request can be granted. Synthetic tests cover running and queued unlocks, concurrent attempts, reauthentication, save/close overlap, creation queued behind a lock, canceled background authentication, clipboard lock/shutdown callbacks, and unique temporary paths. The encrypted vault format did not change.

Final Windows 11 / Python 3.12.3 source suite: **129 run, 127 passed, 0 failed, 2 skipped** (see final run before publication). A source-only copy made from tracked and proposed untracked files passed asset/layout checks, `compileall`, the headless self-test, and 13 vault baseline tests when its temporary directory was kept in the ignored workspace. `pip check` passed. `pip-audit 2.10.1` on both exact pinned requirements files with `--no-deps --disable-pip --strict` reported no known vulnerabilities. Pins have no wheel hashes, and the GitHub Actions dependencies use mutable version tags; those remain supply-chain risks. The installed CustomTkinter wheel's metadata says CC0 while its included LICENSE and upstream repository say MIT; notices follow the actual LICENSE. Pillow and cffi notice labels were also corrected from their installed license files.

The current one-file executable rebuilt locally and passed its bundled `--selftest` after setting `TEMP` and `TMP` to an isolated ignored workspace folder. Its GUI opened visibly and enabled, exited through the tray, and reopened twice using the same disposable fictional vault. The initial smoke harness incorrectly expected a tray window at foreground launch; the corrected harness passed both launches. A full installed executable and installer desktop checklist is still open. NSIS was not installed. Two attempts to obtain the official portable NSIS 3.11 archive through SourceForge yielded HTML instead of the 2.4 MB ZIP; both failed the [published SHA-256](https://sourceforge.net/projects/nsis/files/NSIS%203/3.11/nsis-3.11.zip/download) check, and neither was extracted or executed. **No installer was compiled or installed.** Clean install, first launch, unlock, Vault Summon, native Hello, tray/startup, Exit, upgrade, data and sidecar preservation, uninstall, reinstall, and registration cleanup are all **UNVERIFIED** for the installer. Static review also found that fixed-name Start Menu and desktop shortcuts can be overwritten on install and deleted on uninstall without proving ownership; resolve and test that behavior before distribution. Perform the [disposable Windows verification procedure](RELEASE_CHECKLIST.md) before any binary distribution. The CI YAML is reviewed but has not run on GitHub.
