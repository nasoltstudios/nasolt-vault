# Nasolt Vault app icons

The XP-inspired master icon was created with OpenAI's built-in image generation tool using Nasolt's original geometric padlock mark as the reference. `nasolt-vault-xp-master.png` is the source image; `python tools/make_icon.py` generates the desktop sizes from it.

Use `nasolt-vault-16.png` through `nasolt-vault-1024.png` for square app and repository artwork. The Windows executable uses `../app.ico`; the application UI uses `../app.png`. All sizes share the same mark.
